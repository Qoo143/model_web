# 圖書館 RAG Agent 系統

## 技術棧

- **Frontend**: Vue 3 + TypeScript + Tailwind CSS + Pinia
- **Backend**: FastAPI + SQLAlchemy 2.0 + LangChain
- **AI/ML**: Ollama + BGE-M3 + Chroma
- **Infra**: Docker + MySQL 8.0

## 程式碼風格

- Python: PEP 8, type hints, snake_case
- TypeScript: ESLint, camelCase (變數), PascalCase (組件)
